# Инструкция по использованию

## 1) Подготовка

- Установите PostgreSQL.
- Создайте базу `confectionery`.
- Убедитесь, что знаете логин/пароль PostgreSQL.

## 2) Запуск backend

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:DATABASE_URL="postgresql+psycopg://postgres:YOUR_PASSWORD@localhost:5432/confectionery"
alembic upgrade head
uvicorn app.main:app --reload --port 8000
```

Проверка:

- [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## 3) Запуск frontend

Из корня проекта:

```powershell
python -m http.server 8080
```

Открыть:

- [http://127.0.0.1:8080](http://127.0.0.1:8080)

## 4) Основные действия в интерфейсе

- **Заказы**: создание, редактирование, удаление.
- **Склад**: добавление ингредиентов, приход.
- **Календарь**: календарный вид операций по дням.
- **Техкарты**: рецептуры, шаги, оборудование.
- **Настройки**: статусы/удаление сотрудников и оборудования.

## 5) Планирование

- Откройте страницу `Календарь`.
- Нажмите кнопку `Запустить планирование`.
- Приложение вызывает `POST /api/planning/run` и обновляет расписание.

## 6) Частые проблемы

- **Ошибка PostgreSQL auth failed**  
  Проверьте `DATABASE_URL` и пароль пользователя.

- **`psql` не найден**  
  Добавьте `C:\Program Files\PostgreSQL\<version>\bin` в `PATH`.

- **PowerShell блокирует activate.ps1**  
  Используйте запуск через `.\.venv\Scripts\python.exe` без активации.
# Руководство пользователя

## Вход в систему

1. Откройте приложение
2. На странице авторизации введите любые логин и пароль
3. Нажмите кнопку "Войти"

## Работа с заказами

### Создание нового заказа (Сценарий 1)

1. Перейдите на страницу **"Заказы"**
2. Нажмите кнопку **"Создать заказ"**
3. В диалоговом окне:
   - Выберите **вид изделия** из списка (Торт Прага, Чизкейк манго, и т.д.)
   - Система автоматически покажет рецептуру и этапы производства
   - Укажите **количество единиц**
   - Выберите дату **"Закончить не позднее"** (не может быть в прошлом)
   - При необходимости укажите дату **"Начать не ранее"**
4. Нажмите **"Запланировать"**

**Результат:**
- ✅ **Успех**: Заказ создан, вы будете перенаправлены в календарь
- ❌ **Ошибка**: Появится сообщение о нехватке конкретных ингредиентов с количеством

### Редактирование заказа (Сценарий 4)

1. В таблице заказов найдите нужный заказ
2. Нажмите кнопку **с иконкой карандаша**
3. Измените параметры (количество, дату выдачи)
4. Нажмите **"Сохранить"**
5. Система перепланирует расписание автоматически

### Удаление заказа (Сценарий 4)

1. Нажмите кнопку **с иконкой корзины** у заказа
2. Подтвердите удаление
3. Заказ будет удален, сырьё вернется на склад, расписание пересчитается

## Работа со складом

### Добавление нового ингредиента (Сценарий 2)

1. Перейдите на страницу **"Склад"**
2. Нажмите **"Добавить ингредиент"**
3. Заполните:
   - **Название** (например, "Сливки 33%")
   - **Единицу измерения** (литры, кг, шт)
   - **Срок хранения** в днях
4. Нажмите **"Сохранить"**
5. Новый ингредиент появится в таблице с нулевым остатком

### Приход товара на склад (Сценарий 2)

1. В таблице ингредиентов найдите нужный
2. Нажмите **"Приход на склад"**
3. Укажите:
   - **Количество** (должно быть больше 0)
   - **Дату поступления**
4. Нажмите **"Подтвердить приход"**
5. Система:
   - Обновит остаток (прибавит количество)
   - Рассчитает дату годности (дата поступления + срок хранения)
   - Покажет уведомление с новым остатком и датой годности

## Просмотр расписания

### Расписание операций (Сценарий 3)

1. Перейдите на страницу **"Календарь"**
2. Выберите период отображения: **День / Неделя / Месяц**
3. Операции показаны с цветовой кодировкой:
   - 🟢 **Зеленый** - активные заказы (выполняются сейчас)
   - 🔵 **Синий** - предстоящие операции
   - 🟠 **Оранжевый** - поставки

4. **Клик по операции** покажет детали:
   - Название операции
   - Кондитер (исполнитель)
   - Оборудование
   - Время начала и окончания
   - ID заказа

### Загрузка ресурсов (Сценарий 3)

1. Переключитесь на вкладку **"Загрузка ресурсов"**
2. Вы увидите:
   - **Кондитеров** с процентом загрузки и списком операций
   - **Оборудование** с временными слотами использования
3. Можно выбрать конкретного кондитера для детального расписания
4. Нажмите **"Экспорт"** для скачивания расписания (в прототипе - имитация)

## Технологические карты

1. Перейдите на страницу **"Тех. карты"**
2. Вы увидите 4 изделия с:
   - Полным списком ингредиентов и **текущими остатками на складе**
   - Индикаторами достаточности ингредиентов
   - Списком необходимого оборудования
   - Пошаговым технологическим процессом с длительностью
3. Внизу страницы - **сводная таблица остатков всех ингредиентов**

## Настройки

### Управление исполнителями

1. Перейдите в **"Настройки"** → вкладка **"Исполнители"**
2. Доступные действия:
   - Просмотр списка кондитеров
   - Изменение статуса (Свободен / Работает)
   - Просмотр загрузки
   - Добавление нового сотрудника

### Управление оборудованием

1. Вкладка **"Оборудование"**
2. Доступные действия:
   - Просмотр всего оборудования
   - Изменение статуса (Свободно / Работает / На ремонте)

### Просмотр заказов

1. Вкладка **"Заказы"**
2. Функции:
   - Поиск по ID или названию изделия
   - Фильтрация по статусу
   - Сортировка

## Уведомления

Система показывает уведомления (toast) при:
- ✅ Успешном создании заказа
- ❌ Ошибке нехватки ингредиентов
- ✅ Добавлении ингредиента
- ✅ Приходе товара на склад
- ✅ Изменении заказа
- ✅ Удалении заказа
- ℹ️ Экспорте расписания

## Индикаторы состояния

- 🔴 **Красный бейдж** "Низкий уровень" - остаток ≤ критического порога
- 🔴 **Красный бейдж** "Недостаточно" - для производства не хватает
- 🟢 **Зеленый бейдж** "В наличии" - ингредиент доступен
- 🟢 **Зеленый статус** "Запланирован" - заказ в очереди

## Валидация

Система автоматически проверяет:
- ❌ Дата выдачи не может быть в прошлом
- ❌ Количество должно быть больше 0
- ❌ Все обязательные поля должны быть заполнены
- ❌ Наличие достаточного количества ингредиентов
